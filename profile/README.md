## Обзор проекта

**QGroundControl (QGC)** — наземная станция управления с открытым исходным кодом, предназначенная для настройки, планирования миссий и мониторинга беспилотных аппаратов. Программа широко используется с автопилотами на базе **PX4** и **ArduPilot** и предоставляет единый интерфейс для взаимодействия с различными типами UAV.

Через QGroundControl можно выполнять первоначальную конфигурацию аппарата, работать с параметрами автопилота, проверять датчики и радиоуправление, создавать маршруты на карте и контролировать телеметрию во время работы системы. Приложение поддерживает различные типы аппаратов, включая мультикоптеры, самолёты, VTOL и другие совместимые платформы.

Одно из ключевых преимуществ QGC — объединение настройки и планирования миссий в одном интерфейсе. Пользователь может подготовить аппарат, построить маршрут с набором точек и команд, сохранить миссию, а затем наблюдать за состоянием UAV и поступающими телеметрическими данными.

## Основные возможности

| Функция | Назначение |
|---|---|
| **Vehicle Setup** | Первоначальная настройка совместимого автопилота |
| **Mission Planning** | Создание маршрутов и последовательностей команд |
| **Flight Map** | Отображение положения аппарата на карте |
| **Telemetry** | Просмотр параметров UAV в реальном времени |
| **Parameters** | Просмотр и изменение параметров автопилота |
| **Sensor Calibration** | Калибровка поддерживаемых датчиков |
| **Radio Setup** | Настройка и проверка RC-управления |
| **Flight Modes** | Работа с поддерживаемыми режимами полёта |
| **Geofence** | Настройка географических ограничений |
| **MAVLink** | Связь с совместимыми системами через протокол MAVLink |
| **PX4** | Полноценная интеграция с экосистемой PX4 |
| **ArduPilot** | Поддержка совместимых аппаратов на ArduPilot |

Набор доступных функций зависит от используемой прошивки автопилота, типа аппарата и подключённого оборудования. Некоторые параметры и страницы конфигурации могут отличаться между PX4 и ArduPilot.

## Планирование миссий и телеметрия

В режиме планирования **QGroundControl** позволяет создавать последовательность маршрутных точек и других поддерживаемых элементов миссии непосредственно на карте. Для каждой точки могут быть доступны дополнительные параметры, определяемые прошивкой и типом используемого аппарата.

Подготовленную миссию можно сохранить для последующего использования или передать на совместимый автопилот. Перед выполнением маршрута необходимо проверить точки, высоты, ограничения и настройки самого UAV.

Во время работы QGC отображает поступающую телеметрию и положение аппарата. Интерфейс позволяет контролировать основные параметры системы и отслеживать состояние соединения с автопилотом.

Перед изменением параметров автопилота рекомендуется сохранить текущую рабочую конфигурацию и ознакомиться с документацией используемой версии PX4 или ArduPilot.

## Настройка беспилотного аппарата

После подключения совместимого автопилота **QGroundControl** определяет аппарат и предоставляет доступные средства конфигурации. При первоначальной настройке обычно проверяются прошивка, ориентация контроллера, датчики, радиоуправление, режимы полёта и другие необходимые параметры.

QGC также позволяет работать с большим количеством параметров автопилота вручную. Такой режим полезен при расширенной настройке, однако изменять неизвестные параметры без документации не рекомендуется.

Перед первым полётом необходимо отдельно проверить работу управления, корректность показаний датчиков, GPS, режимы полёта, Failsafe и остальные критически важные компоненты системы.

## Быстрый старт

1. Запустите **QGroundControl**.
2. Подключите совместимый полётный контроллер или автопилот.
3. Дождитесь определения аппарата программой.
4. Проверьте установленную прошивку и тип транспортного средства.
5. Выполните необходимую калибровку датчиков.
6. Настройте и проверьте RC-управление.
7. Проверьте режимы полёта и параметры безопасности.
8. Откройте карту и подготовьте миссию при необходимости.
9. Проверьте маршрутные точки, высоты и ограничения.
10. Перед эксплуатацией выполните полную проверку аппарата и связи.
